# v4.7：可破坏掩体与台球自由球

## 坦克

- 默认掩体承受三发炮弹。击中后闪亮并出现裂纹，最后一发击碎掩体，产生小范围碎石和原创碎裂音效。
- 可破坏掩体吸收命中的炮弹；场地外墙仍按原反弹次数处理。打碎后，坦克与子弹都可从缺口通过。
- 同一物理子步内，所有炮弹先按同一份掩体状态判定，再统一结算耐久，避免后处理的炮弹因顺序意外穿透刚毁掉的墙。
- 贴墙时炮口进入掩体也可正常造成伤害。掩体损伤不会额外加比分。
- 设置增加“固定不可破坏／两发／三发／四发击碎”，默认三发，单独保存；固定档保留原掩体反弹。
- 每次双方重新出生的新回合，恢复该场地完整掩体；双方出发条件一致。

## 台球

- 白球落袋，且本局没有结束时，换手给对方自由球。白球不再自动摆到固定位置。
- 下一位玩家可在整张球桌内点选或拖动位置，看到白球预览；合法位置显示绿圈，非法位置显示红叉。
- 不允许与其他球重叠、超出有效球桌或放在袋口里。确认前不可击球。
- 当前玩家自己一端显示“确认摆球”；确认后恢复力度和瞄准，再点击球。另一端的按钮区域不会确认摆放。
- 暂停保留摆放候选点；重开清空自由球状态。未分色时犯规进的目标球仍按原规则放回，清台白球同落仍判负，不进入自由球流程。
