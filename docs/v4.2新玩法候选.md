# 下一批小游戏候选

以下是供选择的玩法大纲，本版尚未加入。共同目标：两个拇指就能开始、面对面操作对等、胜负一眼看懂、单局约 20～45 秒。

| 玩法 | 操作与胜负 | 有趣之处 | 要防的问题 |
| --- | --- | --- | --- |
| 圈地涂鸦 | 每人一根摇杆，绕出闭合区域染色；30 秒后面积大者赢，走出领地的线会被对手截断 | 争夺空间、偷家与及时撤回，画面会越玩越丰富 | 断线判定必须清楚；起点和障碍保持点对称 |
| 磁力抢宝 | 各守一端，拖动磁铁，按键切换吸引／排斥，把中央金属宝物送进自己的收集槽 | 能抢、能拦，也能用排斥假动作 | 磁场有距离上限，避免站着吸就能赢；别让特效遮住宝物 |
| 走钢丝 | 两边各点左右按钮调整小人的平衡；双方遭遇同一阵风，先走到旗子或坚持更久者胜 | 小幅补救、险些摔下后救回来，比拼控制节奏 | 只用触摸，不用手机陀螺仪，避免共用设备互相干扰 |
| 节奏对拍 | 两人听同一小段原创节奏，按自己的两颗按钮；准确度和连续命中决定分数 | 耳朵与手指配合，区别于纯拼手速 | 按事件时间判定而非绘制帧；提供统一的视觉节拍与延迟校准 |

建议优先做“圈地涂鸦”：操作直观，攻防层次与现有游戏差别最大。“磁力抢宝”适合继续发挥已有碰撞与物理反馈。

WorkBuddy 的原始研究与其他方向在 [调研报告](WorkBuddy评审/v4.2机关与玩法建议.md)。这里是主开发筛选后的提案，并非对其报告逐项采纳。抽木塔需要更完整的刚体堆叠，当前不宜为了增加数量仓促实现；共享气球的爆炸归属还需要更明确的规则。
