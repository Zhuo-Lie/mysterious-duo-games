# v3.1 · 面对面对战与首轮玩法打磨

应用仍为“神秘双人小游戏”，版本号 3.1 / 12。保留包名与签名，可覆盖安装。相扑规则、推力、跨步、角力和音频参数均未重调。

## 本版变化

- 新增七款：取消单端横排比分，改为红蓝两条侧栏，显示比分／圈数／棋色与当前回合；赛车计时也移到侧栏。
- 实时游戏：两端相同大小、相同距离的说明与操作提示，上端旋转 180 度。赛车中心的加速／刹车／打转提示分别朝向双方。
- 新增七款的结算页也有双方各自朝向的结果、再战和返回按钮，按任一端再战都会轮换先手。
- 棋类：确认和悔棋放在当前玩家一端，随轮次换边；棋盘方向保持固定。共享屏幕无法识别真实操作者，此设计减少误触，并非防作弊身份验证。
- 台球：力度条和击球按钮随玩家换端，触摸坐标逆变换。允许一根手指瞄准、另一根调力度；无关手指不会阻塞整屏。瞄准线在首次碰球或库边停止，增加白球接触圈和目标球方向短线。降低最小出杆速度，支持近距离轻击；最大速度保持 890。
- 暂停：恢复后冻结物理 1.5 秒，双方可重新按好球拍／刹车，比赛计时不增长。显式暂停或音量面板在切后台再回来时保留。
- 冰上桌球／弹球：修复球已进入门内通道后斜向移动时被拉回场内的问题；门柱通道考虑球半径。补画与物理边界一致的侧墙。
- 弹球：近水平运动持续 1.5 秒后，沿原纵向运动方向渐进加速，打破纯水平僵局；完全水平时按交替发球方向兜底，不按所在半场突然反向。不改比分、不设置强制胜负或总时限。
- 准备键只响应画出的按钮区域；重新开局清空台球每杆内部状态。

## 案例与取舍

查阅 [JindoBlu 官方同屏双人介绍](https://www.jindoblu.com/2-player-games-the-challenge/) 与 [Plato 官方台球操作说明](https://platoapp.com/en/games/pool)。前者明确一台设备两人游玩，后者介绍点桌面瞄准、力度控制、白球与目标球瞄准线。此处借鉴交互思路，自行实现，不复制素材，也未安装或声称试玩这些应用。

本项目仍采用每人三球的简化台球：对方球入袋记给对方；进本色球可继续；清台时白球落袋判负。没有改成完整八球规则。瞄准提示仅表示首次接触，不承诺后续进球。
