# 小鸡封面

最终资源：[chicken_duel.png](../../app/src/main/res/drawable-nodpi/chicken_duel.png)。用于安卓桌面图标和大厅品牌插画。

用户原型：[用户小鸡原型.png](用户小鸡原型.png)。以用户补充的银灰中分、黄脸、黑衣背带裤小鸡为原型；最新要求是保持简笔画与对角线构图。

使用系统内置 imagegen，参考图生成。未调用付费外部 API 脚本，未增加游戏运行时依赖。先前较复杂的黑发对称方案已放弃，当前只使用银灰中分的简笔对角线版本。
