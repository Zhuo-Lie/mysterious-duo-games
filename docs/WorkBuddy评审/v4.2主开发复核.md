# v4.2 WorkBuddy 建议复核

通过 computer-use 技能向 WorkBuddy 新建调研任务。限定只读 BallDuel、ArcadeScreens，允许写研究报告，不改源码或执行程序。其输出为 `v4.2机关与玩法建议.md`。

采纳：推荐卡在触摸按下时停止轮换，松手后重新计时；增加显式暂停／继续。读屏焦点与普通焦点停留时不改推荐内容。理由是避免用户看着某游戏、按下后恰逢轮换而进入另一款。

未采纳：报告称 PING_PONG 的 ty 可以任意改变，实际 `aim()` 只有 HOCKEY 分支会给 ty 赋值；PING_PONG 的 py 始终固定，因此该问题不成立。

未采纳：报告建议点对称的上下机关改成反向角速度。对于当前 180° 旋转对称场地，位置与速度都应取负，但角速度应相同；直接把一边的角速度取反，会破坏这一对称关系。本版保留同一布局两根横杆相同的角速度，通过位置点对称保持双方一致；不同地图有不同转向。

未采纳：在纯回弹弹球加入 spinner 加成，与用户先保持纯回弹的选择冲突。本版只丰富机关弹珠。

调研中的真实机器名称与链接仅作设计线索，没有把未验证细节当成本项目实现依据。最终规则与触控、原生视图测试由主开发在本地验证；报告不算真机测试。
