# WorkBuddy 评审的复核与采纳

WorkBuddy 独立阅读代码，主开发负责复现、取舍、修改与验证。其报告为评审意见，不能直接当作测试结论。

| 首轮条目 | 主开发处理 | 验证 |
| --- | --- | --- |
| 多指数量闸门 | 采纳。取消整屏 pointer 数量限制；台球分别登记瞄准、力度手指，额外指针不抢占通道 | 原生双指事件下仍能确认落子；台球按通道处理 |
| 对方替当前手落子 | 部分采纳。共享棋盘无法凭触点识别真实操作者；当前玩家一端才显示确认／悔棋，非当前端确认不生效 | 上下端交替确认与非当前端点击测试；不宣称防作弊 |
| 赛车恢复时刹车释放 | 采纳问题，采用不同修复。恢复冻结物理 1.5 秒，支持重新按住，避免保留旧刹车导致松手后仍刹车 | 弯内暂停／恢复／重新按住，期间距离不增加、恢复后不因中断打转 |
| 球门斜角拉回 | 采纳。进门后在门内通道横向反射，不再把球拉回内场。极慢球向门内滚动时给最小通道速度，避免停在球槌不可达处 | 上下门斜射与低速通道测试；侧墙绘制匹配现有碰撞边界 |
| 对方球进袋记给对方 | 保留约定规则，未照报告改成另一套规则。玩法页本已明示；三球清台为简化玩法 | 现有误入对方球、清台、清台白球同落测试继续通过 |

另外采纳了准备按钮精确热区、暂停面板跨后台保留、台球低力度空间的问题。报告对“倒计时 3 不响”的表述需要结合进入倒计时当帧的准备音一起判断，没有盲目增加重复音。

自行补充：首次碰撞瞄准预览、近水平弹球僵局处理、双端结果／再战／返回，保持已认可的相扑参数。

所有视图验证在桌面安卓环境进行，不是手机真机试玩。原始评审保留原行号，改版后位置可能变化。

## 第二轮复核

已收到 `v3.1面对面复核.md`，按快照核对：

- **采纳 V3**：弹球僵局处理保留原纵向速度符号，按每秒 260 的加速度渐进加速；不再根据所在半场直接反向赋值。补测整个加速序列无反向、无突变。
- **采纳 V2 的提示改进**：五子棋确认键显示“红／蓝方确认 · 行列”，按前可核对落点。不给共享棋盘的选点加半屏限制，避免当前玩家不能选择对面半盘。
- **V1 不采用半屏限制**：台球桌面也是完整共享操作面，当前玩家需要瞄准全桌；按触点半屏判断操作者会禁止合法瞄准。力度／击球按钮已有当前端保护，桌面无法识别故意伸手的真实玩家，与棋盘一样不宣称防作弊。
- **V4 为半径修正，非新缺陷**：可见门口 x=137..263，球半径 9，因此球心完整通过的区间是 146..254。x=140 的球与左门柱重叠 6，不能按“球心落在线内”算进球。保留半径修正，并已测中心斜射与低速入门。
- **V5 保留 1.5 秒缓冲**：缓冲期间可提前重新按住；故意不刹车后继续加速是正常规则，不能据此认定恢复失败。是否需要更长缓冲留给真实双人体验，不强制双方恢复时都刹车，因为直道上松手加速也是合法选择。
- **同端额外手指**：当前所有实时游戏明确单指操作，额外手指不接管已登记手指；不新增多指增益或隐式接力。
- **阴影**：控件整体旋转让阴影相对于各自玩家的方向一致，保留；消除结算时的顶部图标残影。
- **双人杯／单人 AI**：有价值的后续候选，当前优先完成双人公平交互，不将它们插入本轮已稳定的规则和入口。

两份外部评审均未执行编译或真机测试；主开发的规则与原生视图检查另记在 v3.1开发记录中。
