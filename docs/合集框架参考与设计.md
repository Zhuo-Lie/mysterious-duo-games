## 本项目的设计判断

1. 玩家的第一步是选游戏。大厅用大卡片呈现轮廓鲜明的场景，按“全部、拼反应、球类、棋类”筛选。
2. 熟悉的相扑可直接开局；其他卡片先显示怎样操作、怎样获胜。未完成的游戏明确写“玩法预览”，开始按钮显示“即将开场”。
3. 红蓝表示两位玩家。黄色强调主操作，暖纸色承载文字；所有游戏插画延续粗黑描边与平涂色块，统一视觉语言。
4. 不提前增加账号、社交、联网、货币或商城，先让两个人选得明白、看得懂、开始得快。
5. 暂用安卓原生滚动、按钮、文字布局和返回机制，复用现有音效与纸卡。插画用项目原生 Canvas 矢量绘制，不引入体积大且暂时用不到的引擎或图片服务。
