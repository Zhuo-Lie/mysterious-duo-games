# 新功能选择记录

本轮已选择 **趣味变局**：机关弹珠每个得分回合换障碍，坦克每个击毁回合安全换掩体，赛车再战可随机换赛道。以上均有固定模式开关。

针对原乒乓球、现名“弹球”，用户选择 **先保持纯回弹，试玩后再选**。下面是候选，不属于本版已实现功能：

| 候选 | 趣味来源 | 取舍 |
| --- | --- | --- |
| 弹球回合机关 | 每分后换中央障碍，改变反弹角度 | 节奏丰富，但会改变当前纯回弹手感 |
| 弹球蓄力反击 | 连续接球积攒一次双方可见的重击 | 有攻防选择，需要防止领先方滚雪球 |
| 双人杯 | 挑选若干小游戏，先赢三局捧杯 | 强化跨游戏连续挑战，不必改变单局规则 |
| 练习模式 | 一人熟悉摇杆、反弹和发力 | 对新玩家友好，但需要额外设计陪练行为 |

“机关弹珠”是原双挡板游戏的推荐暂名。备选名：**弹珠擂台**（突出对抗）、**双拍弹珠**（突出左右操作）。
