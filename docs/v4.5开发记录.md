# v4.5：缩小今日擂台

今日擂台改成紧凑横排：左边是对应游戏插画，右边为名称、两行短介绍与开局入口。图片区域高 104dp，标题栏集中放页码、左右翻页和暂停按钮，移除单独占一行的圆点导航。

标准字号下推荐卡高约 162dp，相比 v4.4 的纵向大卡减少约一半；卡片与游戏列表之间的留白也缩小。保留图片与名称同步、整页滑动、自动推荐、暂停及点击当前页开局。

使用原有游戏插画与 ViewFlipper，无新增依赖。Android 9／15 的 18 项原生 View 测试通过，增加卡片不超过 180dp 的尺寸检查；图片对应、左右滑动、暂停、竖向滚动与开局测试继续通过。尚未连接手机实测。
