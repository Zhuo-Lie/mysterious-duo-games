# v3.0 · 神秘双人小游戏

日期：2026-10-17。内部版本号 11，包名 `com.local.tapsumo`，沿用原调试签名，可覆盖 v1.x／v2.0。

## 本版交付

**八款均已接入实际对战：相扑、乒乓球、台球、井字棋、冰上桌球、弹球、赛车、五子棋。** 其余七款从 v2.0 的插画与玩法预览变成有输入、规则、胜负、结算与再战的初版。新游戏是否已经足够好玩，仍以真实双人试玩判断。

- 大厅改名“神秘双人小游戏”，分类和玩法页保留，所有入口可开始。
- 新增双方准备、三秒倒计时、结算、再战、暂停、重新开局、返回大厅。
- 实时游戏支持双方独立手指归属；松手、取消、暂停时释放输入，拖过中线不会抢对方的操控。
- 五子棋点选后确认，支持双方同意悔一手；再战交换先手和执黑者，始终黑棋先走。
- 井字棋支持连线、平局、悔棋和轮换先手。
- 乒乓球可通过拍边与移动改变回球方向，接球逐渐加速，先得 5 分。
- 冰上桌球有球槌碰撞、半场限制、边墙和中央球门，先得 5 分。长期模拟发现的球槌挤穿边墙问题已修复。
- 弹球有两侧各一对短促弹起的挡板、中央弹力柱和失球口；按时机操作，先得 5 分。
- 赛车是单指刹车赛，松手自动加速、弯前按住减速、超速打转，三圈冲线；完全相同输入可平局。
- 台球是简化双人规则：每方三球、六个球袋，瞄准与力度独立，进本色球继续，未进或白球落袋换人，白球自动放回无重叠处；清台时白球同落判负。
- 大厅累计红蓝胜场和平局，本机保存，可查看或清零；重复结果通知不重复记分，中止不记分。
- 共用原有音效设置与纸卡音量面板，本地音量、总静音和推力设置保留。

## 相扑保持的内容

`Match.java`、`PushMotion.java`、`DuelMotion.java`、`VisualPosition.java` 与八个音频资源均未改变。相扑的推力、步幅、收势、等速来回角力、边缘视觉收敛及真正出界判定继续沿用已有版本。

只在相扑结算时接入合集累计比分，并补齐在立刻返回／切后台的情况下记录结果。原有相扑切后台重置的行为保持；新游戏切后台暂停当前对局。

## 封面

用户先提出小鸡双人对抗，随后补充银灰中分、黄脸背带裤原型，并明确“保持简笔画、对角线构图”。最终采用左上蓝方、右下红方的双鸡篮球对抗插画，替换桌面图标和大厅品牌图。

使用内置 imagegen，最终 PNG 已放入项目资源，完整提示词、原型与使用位置见 [生成说明](美术与封面/生成说明.md)。游戏卡片和场景继续使用原项目原生矢量绘图，没有引入图片服务或第三方运行时。

## 验证结果

### 编译与安装包

- Windows 自带 PowerShell 下运行编译脚本、快速检查脚本，通过。
- Java 源码编译、DEX 打包、APK 对齐和 v1/v2/v3 签名验证通过。
- 应用名、3.0 版本、内部版本号 11、图标资源均已在 APK 中检查。
- 包名与旧签名一致，没有新增联网或其他应用权限。

### 规则与模型

- 原有相扑全部规则、动作、视觉映射、音量和八个 WAV 资源检查通过。
- 棋类检查横、竖、双斜线、占位拒绝、越界、平局、撤回、先手及自由规则长连。
- 三款球类检查五分终局、重开、边墙、拍边回球、半场限制、挡板收势、持续随机操作下的有限数值、边界和速度上限。
- 赛车检查三圈胜负、完全相同输入平局和帧率独立；按时机刹车的模拟约 17.29 秒完成，并胜过全程刹车。
- 台球检查球动期间禁止重复击球、球停稳、本色继续、对手球计分、白球回台不重叠、第三球获胜和清台白球同落判负。
- 合集目录、实际启动状态、比分累计与清零检查通过。

### 安卓原生视图

Maven／Robolectric 执行 **8 项测试，0 失败、0 错误、0 跳过**。覆盖 Android 9（API 28）和 Android 15（API 35）：

- 七款新游戏真实 View 的双方准备、倒计时、实际触摸落子／确认／击球、暂停冻结与场景渲染。
