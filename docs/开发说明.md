# 开发说明 · v4.7

安卓离线同屏双人游戏，应用名“神秘双人小游戏”，九款已接入。Java 原生 View／Canvas，最低 Android 6，目标 Android 15；无账号、联网权限、广告或服务器。

## 源码地图

目录 `app/src/main/java/com/local/tapsumo/`：

| 文件 | 职责 |
| --- | --- |
| MainActivity | 页面路由、共用纸卡设置、玩法选项、累计比分；内部 SumoView 保留成熟相扑 |
| ArcadeScreens／GameCatalog／GameNavigator | 大厅、玩法卡、九款注册与导航；旧 PING_PONG 编号保留，但显示名已为“弹球” |
| MiniGameView | 八款新场景、双方准备、输入通道、场地渲染、侧边纸牌与调节入口、暂停和结算 |
| GameOptions | 各游戏对称参数；MiniGameView 按游戏编号保存到 game-options 偏好 |
| BoardMatch | 三／五子棋规则，连线、满盘与撤回；本轮未改规则 |
| BallDuel | 纯回弹、大球槌冰球、独立四挡板机关弹珠；三组对称障碍、有限速度与随机回合切换 |
| PoolMatch | 十个目标球、白球、首次合法分色、回合、碰撞、犯规与有限预瞄 |
| RaceMatch | 自由摇杆驾驶、三条路径、道路距离、顺序检查点、圈数与终点 |
| TankMatch／DriveMath | 履带差速、独立炮塔、三张对称掩体、弹道反弹、装甲、回合重置与通用几何 |
| Match／PushMotion／DuelMotion／VisualPosition | 原相扑发力、跨步与视觉位置，保持稳定 |
| GameArtView／ArcadeTheme／PaperPanelDrawable | 原创矢量卡片、红蓝纸牌、粗描边与纸质面板 |
| GameAudio／SoundSettings | 八个 PCM 声音、音色和分组音量 |
| SeriesScore | 九款共用的本地累计胜场／平局 |

坦克每个触摸通道为“玩家＋左／右摇杆”，四指互不抢占。实时球类初次按下绑定半场，移动跨中线不换边。机关弹珠独立四挡板。棋盘与台球完整桌面共享，不能用触点半屏识别真实操作者；确认／力度／击球控件放在当前玩家端。

游戏主逻辑固定 120 Hz，球碰撞／炮弹子步 240 Hz。暂停释放输入，恢复留 1.5 秒重新操作时间；显式暂停／设置面板跨后台保留。每回合换障碍时先回中发球或清弹重置，避免生成墙体困住玩家。

## 编译与检查

- 双击根目录 `编译安装包.cmd`，或 `./build-apk.ps1`。
- 规则／动画／音频：`./tools/test-project.ps1`，也可双击 `检查项目.cmd`。
- Android 9／15 视图：`./tools/test-android-ui.ps1`，已确认 APK 资源没变时可 `-SkipBuild`。

编译使用 `.tools` 中的 JDK17、Android SDK35，手动打包并连续签名。版本只改 `app/build.gradle`，成品复制到 `安装包/当前版本`。旧 aapt 需用 ASCII 相对构建路径；PowerShell 脚本保留 UTF-8 BOM，以兼容自带 PowerShell。

Maven／Robolectric 仅供开发，不打进 APK。测试报告在 `tools/android-ui-check/target/surefire-reports`，原生渲染在 `docs/界面预览`。自动检查不替代手机触控硬件、延迟、帧率、音量和真人玩法测试。

签名 `.tools/debug.keystore` 必须保留。已保存 `开发备份/v3.1改版前源码.zip`；历史 APK 单独归档。新版本取舍、案例与验证详见 [v4.4开发记录](v4.4开发记录.md)。
