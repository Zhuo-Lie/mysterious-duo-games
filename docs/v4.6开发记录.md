# v4.6：弹球越打越紧张

本轮根据用户提出的时间加速方向，修改的是“弹球”（原乒乓球），不是“机关弹珠”。

- 每分开始先保持原发球速度，持续对拉两秒后，渐进档每秒增加 9×节奏系数的速度，紧张档为 16×系数。
- 原先每次接球增加 20×系数的速度继续保留；总速度封顶 690×系数，不会无限增长。
- 每分重新发球时清空本次对拉时间与拍数，不把上一分的高速度带到下一分。
- 设置里增加“经典／渐进／紧张”三档，默认渐进；经典只保留原接球加速，没有额外时间加速。选项独立保存。
- 两端显示对拉拍数；击中拍面中心时短暂出现“精准回击”。这是反馈，不额外加分或自动增强力度。
- 大厅维持 v4.5 紧凑图片推荐，其他八款规则保留。

[案例研究与跨游戏方向](玩法研究与后续方向.md) 包含官方来源和待选提案；提案尚未实装，不作为本版已完成功能。

## 验证

纯 Java 测试通过：热身、三档区别、速度上限、不同帧率的一致性、每分重置、精准回击不额外得分；原有碰撞、布局与其他游戏测试继续通过。

Android 9／15 原生 View 测试共 20 项通过，新增升温设置持久化、回击画面与暂停不累加对拉时间检查。尚未连接手机实测。
