# v4.3：相扑风格、放大摇杆与弹珠布局重排

## 操作与美术

- 赛车车尾两条半透明白色速度线已移除，保留后轮尘埃。
- 新游戏两端加入红／蓝底色、斜向浅色块和黑色分隔线，参考相扑操作区。球桌与场地保持自己的材质。
- 赛车摇杆半径 44→66，坦克 38→57，均是上一版的 1.5 倍。内圈、拇指帽、描边与触控范围同步调整，输入位移按新半径归一化。
- 摇杆中心改为 y=72／728，完整显示在屏幕内。赛车与坦克场地等比缩放到 90%，给控制区留空间；物理场地、转向和速度规则不变。
- 摇杆说明移到圆盘外，避免拇指帽盖住文字。坦克中间标明左右移动／开火，朝向各自玩家。
- 游戏按钮采用相扑式的纯色、粗黑描边、厚底与黑体；原生大厅按钮也统一为纯色黑体。按钮长文案自动缩小字号以免溢出。

## 机关弹珠：不再全部叠加

三组布局按玩法分工，得分后仍按原设置随机换组：

| 场地 | 使用机关 | 设计取舍 |
| --- | --- | --- |
| 流动弹柱 | 仅两颗左右移动圆柱 | 保留侧边通路，用圆柱制造可读的反弹 |
| 双翼风车 | 仅两根旋转横杆 | 上下间隔 200，杆半长 38、角速度 0.8，观察转动窗口穿越 |
| 错位组合 | 两颗小幅移动圆柱＋两根短旋转杆 | 圆柱半径 19、移动幅度 8；旋转杆错位布置，半长 28、角速度 -0.65，活动区域彼此分开 |

两边始终保持 180° 点对称，发球区域留空；混合布局不会让圆柱与横杆追着彼此挤球。没有加入全屏阻挡或额外加速道具。
