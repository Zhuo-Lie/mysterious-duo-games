# v4.1：比例、声音与动态机关

这轮从“看得清、操作跟手、反馈能分辨”出发，延续粗描边、红蓝色块和暖纸风格。

## 本次变化

- 台球取消横向 84% 压缩，球与球桌恢复等比绘制，瞄准触点也同步修正。木框略收窄，左侧比分宽度 40→32；右侧工具改为房屋、喇叭、滑杆、静音图标，显示在游戏画面上层。
- 为八款新游戏分别合成回弹、球杆碰撞、粉笔落子、冰球碰撞、机械挡板、检查点、棋子落盘、炮声。相扑原有八个声音资源逐字节核对备份，保持一致。公共倒计时与结算旋律保留。
- 赛车标准最高速度 145→185（约 28%），加速 190→255，转向上限 3.8→4.3，摇杆半径 38→44。增加起终点格纹和速度尾迹。引擎循环随实际速度调整响度与音调，动作／引擎音量沿用现有滑杆，暂停、静音、结算、离场停止循环。
- 冰上桌球球门宽度 156→144，约缩小 8%，显示与进球判定使用相同尺寸。
- 坦克行进速度 93→108，转向上限 2.6→3.5，保持差速履带与独立炮塔。子弹半径 4→6，墙体与命中判定也同步扩大。双方子弹碰撞对消，同方不对消；先统一推进所有子弹，再处理对消，最后处理坦克命中。增加对消火花与专属声音。
- 机关弹珠增加三种对称动态机关：水平摆锤、椭圆环舞、八字游走。机关速度参与碰撞，画出运动轨迹，回合间继续随机切换。纯回弹“弹球”保持之前的玩法选择。
- 声音面板在新游戏中显示当前游戏的专属音效，拖动音量后试听当前游戏；相扑保留原有三种发力音选择。

## 复用与依据

沿用现有 Canvas、物理模型、纸质设置面板、SoundPool 和本机测试工具，无新增游戏引擎或运行依赖。当前提供的 Skill 没有专门的原生 Android 游戏物理工具，本次使用已有工程能力。

引擎循环的播放、调速、调音量与停止按 [Android SoundPool 官方文档](https://developer.android.com/reference/android/media/SoundPool) 实现。新声音由 `tools/generate-arcade-audio.cjs` 离线生成，不依赖外部音源。

## 验证与边界

- 全部原有纯 Java 规则测试通过；新增子弹对消、同方子弹、三个机关布局的运动／边界／双方对称测试。
- 18 个 PCM 音频检查格式、幅度、削波、淡出或循环端点通过。
- Android 9 和 Android 15 原生 View 测试共 14 项通过；涵盖台球触点、扩大摇杆、四指坦克、独立挡板、设置持久化、双向结算。预览图为 Robolectric 渲染，不是真机截图。
- 三张赛车地图的自动驾驶测试均能完成；这仅验证可达性，不代表真人体验评分。
- APK 使用原调试签名，versionCode 14 / versionName 4.1，可覆盖安装。真机音色、扬声器低频与多人手感仍需要用户试玩反馈。
