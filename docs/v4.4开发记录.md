# v4.4：今日擂台图片滑动推荐

- 原来占据推荐区的小鸡封面改为标题旁的 40dp 小图，应用图标保持原资源。
- 今日擂台改为九张图片卡，每张展示该游戏已有的专属插画、名称、玩法短句和开局入口。图像是项目的原创游戏插画，不是真机画面截图。
- 图片、标题、说明作为整页左右滑动，自动推荐每五秒换下一款，支持暂停／继续。
- 可手指左右滑动，也可以点击左右箭头；九个圆点和页码显示当前位置。
- 按下暂停计时，松开重新计时；滑动只切页，不开局。竖向手势让给大厅滚动；多指手势不触发点击。
- 点击图片或开局区域进入当前显示的游戏；读屏可使用前／后翻页动作。
- 使用 Android 自带 ViewFlipper、TranslateAnimation 和已有 GameArtView，没有新增依赖或下载素材。

## 验证

Android 9／15 原生 View 测试共 18 项通过，包括九张图片与游戏 id 对应、自动轮换、暂停、手指按住六秒不切页、左右手势、竖滑取消、点击当前页与离开后停止计时。其余游戏交互测试继续通过。
