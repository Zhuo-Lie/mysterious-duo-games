# WorkBuddy 在这个项目里的分工

主开发负责设计取舍、源码修改、编译和验收。WorkBuddy 适合做独立只读检查：分色／胜负边界、地图对称性、交互遗漏和简短试玩方案。

每个大版本优先新建独立任务，给当前文件、准确需求和最多三项检查目标，避免旧版长对话反复扩展。默认先只读，输出限定在 `docs/WorkBuddy评审/版本名.md`，不与主开发同时修改代码。可设置合理时间范围，但不能把它的思考时长当作已完成证据。

不让协作任务读取 `.tools`、签名、个人背景、个人记忆或项目外资料，不让其安装、上传、发布或更改安全设置。日常模型与任务配置按实际工作量选择。

评审意见需要复现：例如球门宽度要扣除球半径；共享棋盘／球台不能用落点半屏判断真实操作者；缺陷与玩法选择分开。只有得到代码、几何或测试证据后才采纳。未安装试玩就不能写成真机体验。

当前原始报告均保留，主开发采纳结果另记；v3.x 行号属于历史快照，v4.0 以后应按当时文件重新核对。
