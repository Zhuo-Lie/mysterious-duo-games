# v2.0 框架预览开发记录

> 历史记录：当前已升级到 v3.0“神秘双人小游戏”，请先看根目录 README.md。

## 已实现

- 新增“双人游乐场”大厅：粗黑描边、红蓝、黄色与暖纸色，八款原创矢量游戏插画。
- 八个项目：相扑、乒乓球、台球、井字棋、冰上桌球、弹球、赛车、五子棋。
- 全部、拼反应、球类、棋类筛选；每款有操作、胜负条件与玩法方向预览。
- 相扑可直接开局，也可从预览页进入。其余七款明确标注“玩法预览／即将开场”，尚未实现完整对战。
- 大厅共用现有纸卡音效、音色、独立音量与静音设置，设置保存在本机。
- 相扑增加小房子返回入口、对局中暂停菜单、结算页返回大厅；重开与双方准备保留。
- 支持手机返回操作，预览返回大厅，对局中先暂停；重新打开应用回到大厅。
- 新增合集图标与桌面名称；沿用旧包名、签名和设置，不需要卸载旧版。

新游戏页面中的局分、控制方式和简化规则属于当前提案，后续会随具体实现与试玩调整；只有相扑规则已经实现并反复打磨。

## 手机试玩时优先观察

1. 大厅字号、两列卡片、上下滚动与分类是否顺手；先看棋类中的井字棋和五子棋。
2. 相扑开始、暂停继续、结算重开、返回大厅能否形成完整循环。
3. 大厅调音量后，进入相扑是否沿用；关闭再开是否保留。
4. 已认可的相扑手感在新壳内是否一致，是否需要改大厅入口而非改规则。

下一步依据真实反馈先改大厅，再选择第二款完整小游戏。当前没有擅自加入跨项目比分或联网功能。
