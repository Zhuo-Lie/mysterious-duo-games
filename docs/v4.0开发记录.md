# v4.0 · 九款游戏、摇杆与趣味变局

## 已实现

- 原“乒乓球”改名 **弹球**，保留纯回弹；卡片改为横拍插画。本轮按用户选择，没有加入蓄力或中央机关。
- 原“弹球”暂名 **机关弹珠**。左右挡板独立，双方共四个触摸通道；扩大中间开口及纵向场地，增加三组旋转对称的弹柱。默认每分后随机换一组、不会连续重复；换场时球先回中发球。
- 冰上桌球扩大纵向场地，默认球半径从 9 增至 12，球槌从 23 增至 27；可再统一调节大小。
- 台球为 **十个目标球＋一个白球**，红蓝目标球各五。每次开局随机先手，首颗合法进球决定击球方目标色，对手分得另一色。玩家红蓝身份与目标球色分开显示。白球犯规时不分色，未分色阶段本杆误入目标球重新摆回；之后进目标球继续、未进或犯规换手。清台白球同落判负。
- 台球预瞄增加目标球方向虚线，默认长度上限 155 逻辑单位，最多一次库边反弹；加强档 230，也仍限一次。遇第二颗目标球便停止，不预测多球连碰、旋转、袋口或精确落点，不提示“必进角度”。可关闭目标球预瞄，保留母球首次接触提示。
- 赛车取消自动前进／刹车机制。改为每人一个方向摇杆，车辆逐渐转向、松手减速、驶出路面减速。依次通过自己的检查点，默认两圈；再战交换起跑车位。三张地图：纸上环线、折角街区、沙丘回环，可选图或在再战时随机轮换。
- 新增 **坦克对战**：每人左侧移动、右侧瞄准并持续开火，四摇杆同时触摸。车身通过左右履带速度差转向，可原地转向、倒车，不能直接横移；炮塔独立、转速有限。默认每车三格装甲、先三次击毁获胜，炮弹默认反弹一次、寿命有限。每个击毁回合结束后清弹并重置双方，默认随机换对称掩体；短暂复活保护，开火解除保护。
- 左侧红蓝纸牌比分／圈数／棋色，较大数字；右侧依次“返、音、调、静音”，把上下空间让给场地。台球额外显示目标球色和当前回合指示。
- 每款提供相应可调选项：获胜分数、节奏、冰球大小、弹珠障碍、赛车圈数／转向／地图、坦克装甲／反弹／地图、台球预瞄、棋类首局先手。选项按游戏保存，取消保持原局；保存会重新准备，避免中途改变一方优势。
- 相扑继续使用原独立画面、标准推力与音量面板；规则／跨步没有重调。井字棋胜负与落子规则未改。

## 第一性原理与取舍

同屏首先需要同等的输入能力，再谈花样。摇杆按“玩家＋摇杆通道”登记手指，首次按下后不会因为移动越过中线而换归属；抬起只释放自己的通道，取消／暂停释放全部。机关弹珠记录四个挡板，不把一侧两次按键合并。左侧比分牌不响应游戏触摸。

所有机关都在得分后切换，不能在坦克身上突然生墙。地图按 180 度对称设计，坦克地图执行带车体尺寸余量的网格通路检查；其中一版回廊过窄，已放宽。赛车检查点必须按序，测试机器人在三图默认两圈约 15–17 秒完成，这不是对真人完赛时间的承诺。

台球预瞄服务于“看懂首次撞击”，保留有限长度、一次反弹和多人碰撞后的未知量；没有加入自动瞄准或直接标记进袋答案。暂不引入黑八与完整赛事罚则。

## 查阅案例与现成能力

- [Plato 官方台球说明](https://platoapp.com/en/games/pool)：点桌面瞄准、力度、母球与目标球瞄准线。借鉴交互思路，不照搬完整八球规则。
- [TankTrouble 官方](https://tanktrouble.com/)：查看坦克迷宫对战案例；本项目自行设计三张对称地图和双摇杆操作。
- [Box2D 官方模拟说明](https://box2d.org/documentation/md_simulation.html)：固定时间步与子步的工程原则。本项目复用现有 120 Hz 游戏循环、球体／炮弹 240 Hz 子步，没有为这次改版临时引入新引擎。
- [JindoBlu 官方同屏合集](https://www.jindoblu.com/2-player-games-the-challenge/)：同设备双人合集的组织方向。

Computer Use 技能用于委派 WorkBuddy 做只读规则与地图复核，限定产出在 docs/WorkBuddy评审，不允许改源码或读取工具／签名／个人资料。未假称安装试玩了这些案例应用。
