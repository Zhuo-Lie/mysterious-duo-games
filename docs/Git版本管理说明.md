# Git 版本管理说明

本项目使用 Git 保存源码变更；GitHub 仓库按私有方式创建。

## 哪些文件会保存

包含游戏源码、原创音效、美术资源、测试、开发脚本和项目文档。

以下内容保留在本机，不随源码推送：

- `.tools/`：本机 JDK、Android SDK、签名密钥和辅助工具。
- `安装包/`、`开发备份/`：安装文件及历史压缩备份。
- `美术风格参考/`：外部游戏参考图片。
- 编译缓存、本机配置、环境变量文件及私钥文件。

注意：GitHub 上的源码备份不包含原签名密钥。请另外妥善备份 `.tools/debug.keystore`，不要公开或提交；丢失或更换密钥可能导致现有安装版本无法直接覆盖升级。

## 换电脑时

克隆源码后还需要准备 JDK 17、Android SDK 35，以及脚本所需的本机工具。当前一键编译脚本依赖 `.tools/` 内的指定路径，克隆仓库本身不等于已具备完整编译环境。安装包应单独获取或在准备好环境后重新编译。

## 日常操作

在项目文件夹打开终端：

```powershell
git status
git add .
git commit -m "说明这次修改"
git push
```

提交前先查看 `git status`，确认只包含本次需要保存的文件。不要用强制推送覆盖历史，也不要将密码、令牌或签名密钥加入仓库。
