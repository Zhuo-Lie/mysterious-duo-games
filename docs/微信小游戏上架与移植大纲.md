# 神秘双人小游戏：微信上架与移植大纲

调研日期：2026-10-17。状态：研究与实施方案，尚未注册账号、接入真实 AppID、完成备案、提交审核或开通广告。

## 1. 推荐路线

保留当前已试玩认可的安卓 v4.7，新增独立微信小游戏工程。先核实主体和上线资质，同时用相扑做移植验证；再加入弹球、坦克形成首批体验版，其余六款分批迁移。最终仍是一个包含九款游戏的合集，不拆成九个账号。

首版目标：打开微信就能同屏双人玩，双方操作公平，保持现有纸感、粗线条、红蓝配色及相扑手感。先不增加付费道具、联网匹配和自建账号系统。

## 2. 现有工程核查

当前是 Java + Android Canvas/原生控件项目，包名 com.local.tapsumo，版本 4.7；Manifest 没有申请联网权限。九款游戏均有现成逻辑，但不存在已完成的微信发布工程。

可以复用的是规则、数值、场地设计、原始美术与原创音效、测试案例；Android 界面、触控、音频和存储调用需要重新实现。APK 不能直接上传成为微信小游戏。资源目录实测约 1.61 MB，这不是微信最终包体大小，也不代表已满足主包限制。

没有在两个常见 Program Files 安装目录发现微信开发者工具；这不等于电脑其他位置没有安装，实施时进一步定位。

## 4. 技术方案：先验证，再确定工具

推荐先用 TypeScript + 微信 Canvas 做相扑技术样机。理由是现有游戏以二维几何绘制和自定义物理为主，直接迁移更容易保留触感，也便于以后输出浏览器试玩版。

备选是 Cocos Creator：它已有官方微信构建流程和平台适配，可减少引擎与资源管理工作。它不会自动把当前 Android Java 工程转换成小游戏。相扑样机需要比较两条路线的触控延迟、绘制性能、文字表现、包体与维护成本，达标后固定一条，不长期维护两套微信实现。[Cocos 官方微信发布文档](https://docs.cocos.com/creator/4.0/manual/zh/editor/publish/publish-wechatgame.html)

拟定模块：

```text
新增微信工程（独立目录，不覆盖安卓工程）
  core/       规则、固定步长模拟、碰撞、随机数
  games/      九款游戏的状态与绘制
  ui/         大厅、纸感弹窗、红蓝计分与设置
  platform/   微信触控、音频、存储、生命周期、广告
  assets/     经授权的图像和音效
  tests/      规则与安卓对照样本、设备检查清单
```

平台能力优先调用微信官方接口，必要时使用成熟引擎；不自己造登录、广告、支付或备案系统。AppID写入项目配置；AppSecret、上传私钥等不放入客户端或公开仓库，首版无后端时不额外引入密钥依赖。

## 5. 分阶段交付与验收

| 阶段 | 交付 | 通过标准 |
| --- | --- | --- |
| A 主体与资质核实 | 账号能力表、材料清单、上线阻碍记录 | 确认合法可执行路径后再扩大移植投入 |
| B 相扑样机 | 微信工具内可运行、手机可预览的相扑 | 持续点击、跨步与尾段小滑动保持；均势仍有来回角力；保持现有推力选项和边缘胜负逻辑 |
| C 首批合集 | 相扑、纯回弹弹球、坦克，含大厅和设置 | 至少四指稳定操作；坦克移动/炮管互不抢触控；双方体验接近 |
| D 其余游戏 | 台球、井字棋、冰上桌球、机关弹珠、赛车、五子棋 | 台球自由球、机关活动障碍、赛车尾尘等已有功能不退化 |
| E 上线准备 | 原创图标、截图、隐私说明、客服入口、体验版 | 冷启动、后台恢复、静音、刘海屏、拒绝授权和无广告情况均可正常玩 |
| F 广告接入 | 真实广告位、失败兜底、频次控制与测试记录 | 资格通过后接入；广告关闭恢复正常；奖励仅在成功完成观看后发放 |
| G 提审与发布 | 上传版本、审核说明、问题修复记录 | 后台实际审核通过后发布；保留可回退版本 |

测试采用相同输入序列比较 Java 与 TypeScript 规则结果；坐标与浮点允许合理误差，胜负、犯规、轮次和得分必须一致。Android 与 iOS 微信真机都测，不以模拟器流畅作为通过标准。赛车/坦克四指、多指中断、手指移出按钮、切后台要重点验证。性能优先保证操作稳定，粒子效果允许按设备降档。

## 6. 我建议同步改进的产品细节

1. 保持紧凑的今日擂台和大游戏区域；首页第一屏明确显示“同一部手机，两个人面对面”。
2. 首次进入每款游戏只显示一张极简操作示意，双方方向正确，之后可跳过。
3. 音量、推力、回合与地图选项本地保存；重开快捷；首次加载按游戏分批组织资源，减少等待。
4. 加一个本地“三局挑战”：三款游戏累计红蓝总分，平局加赛。可加强合集的连续游玩理由，放在基础移植通过后实现。
5. 微信分享卡片直接展示真实对战画面；不强制分享、不把分享当作广告观看成功。
6. 商业发布前重新做完全原创的对抗小鸡标识，保留简笔、对角线、红蓝冲突感；逐项整理图像、字体、音效的来源和授权记录。

## 7. 广告如何安排

主玩法免费；对局中不遮挡场地、摇杆或按钮，不在相扑发力过程中弹广告。先评估低频局间插屏；可选激励视频用于临时外观/主题，不增加伤害、推力或瞄准优势。没有广告或加载失败时能继续核心玩法。

广告展示期间暂停模拟与音频并清空按压状态；关闭后双方准备再恢复，防止一方因此失误。两个人共用一部手机不等于两次广告展示。

腾讯2024年官方培训材料介绍了上架、申请流量主和创建广告位的链路，可以用于理解流程；其中历史门槛、分成和结算周期不能作为2026年承诺。先取得后台资格，再测实际广告展示与留存，不以增加广告次数作为最优先目标。[腾讯官方培训材料（2024）](https://training.tencentads.com/uploads/202406/p3QdnttL_FhMfKa.pdf)
