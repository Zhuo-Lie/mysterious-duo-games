# v4.7：建议先这样试玩

覆盖安装 `安装包/当前版本/神秘双人小游戏-v4.7.apk`。先用默认设置玩，再一次只调一个参数。

| 游戏 | 优先体验 |
| --- | --- |
| 弹球 | 左右拖横拍，拍边与中心回球；目前保持纯回弹 |
| 机关弹珠 | 左／右分别按、一起按，看宽得分口是否有攻防空间；观察每分后的障碍变化 |
| 冰上桌球 | 新场地与大球／大槌是否更舒服；想更慢或更大可从右侧滑杆图标修改 |
| 台球 | 看随机先手；让蓝方先打进红球，检查蓝方目标是否成为红球；体验轻击、有限反弹预瞄、白球犯规 |
| 赛车 | 推向检查点，松手减速；试三图、驶出道路和回到路面；再战会交换起跑车位 |
| 坦克 | 左移右射同时用，试原地转向、倒车、侧向绕掩体、反弹射击、击毁后安全换图 |
| 井字棋／五子棋 | 基本规则保留；五子棋预选与当前玩家一端确认；设置里能选首局先手 |
| 相扑 | 推力、跨步、角力与声音是否仍和认可版本一致 |

坦克最好两人一起试：每人两个拇指，右摇杆推出去会持续开火，松开停火。双方都需要设备支持至少四点触控；本机检查已模拟四指，但手机硬件表现仍以实际体验为准。

新场景左侧是彩色比分纸牌，右侧“返／音／调／静音”。“调”的取消保留当前对局，保存会重新准备，避免一方中途改参数占优势。音量独立保存，不重开对局。

台球有十个目标球，玩家身份与球色分开。首颗合法进球分色后，以所属五个目标球为准；不使用黑八。预测只显示首次接触和有限长度的目标球路径，不保证进袋。

反馈只需说“哪款、做了什么、哪里不舒服”，例如：

> v4.2，坦克。向右转车身舒服，但炮塔跟手还不够快，拐角容易卡。

> v4.2，机关弹珠。左右操作终于分开了，但我希望挡板抬起再快一点。

现有截图来自桌面安卓原生渲染，不是真机截图。性能、声音、四指舒适度与真人对抗节奏仍需要你体验后继续调。

## v4.2 本轮重点

1. 台球：检查圆球与球桌比例，点桌面斜向瞄准是否准确。
2. 赛车：感受更快速度、大摇杆；松手后引擎渐低，静音或暂停后应停止。
3. 坦克：左右拐弯与倒车，试着正面对射让子弹抵消，再走位绕开火线。
4. 机关弹珠：分别体验水平、环舞、八字三种移动机关；两边操作仍保持对称。
5. 冰上桌球：球门只略微缩小，检查守门是否更舒服。
6. 各款声音：右侧喇叭进入设置，动作／引擎滑杆调节音量；相扑仍保留原点击音选择。

## 本轮新增重点

- 赛车：车尾尘埃随行驶产生、停下后散去；引擎声音是否足够清楚。
- 坦克：对射后的短小金属火花，是否比原先大黄圈清楚。
- 冰球：快速斜拖球槌，确认追赶感减少且球不乱飞。
- 弹珠：三种横杆随时间旋转，碰到杆端是否有带动感。
- 台球：轻擦目标球，比较目标方向和短白球分离线。
- 大厅：等待五秒、暂停轮播、按住卡片、切后台再返回。

## v4.3 重点

- 赛车／坦克：大摇杆边缘能否按到，四根手指是否互不干扰。
- 机关弹珠：流动弹柱只放圆柱、双翼风车只放转杆、错位组合保持通路；重点反馈是否有难以脱出的夹角或频繁无机会失球。
- 红蓝操作区与按钮文字是否更接近相扑的观感。

## v4.4 今日擂台

左右滑动卡片看图片是否与名称同步；按住时不换页，竖向仍能滚动大厅；暂停轮播后手动翻页，再点击开局，应进入当前图片对应的游戏。

## v4.6 弹球升温

持续对拉，感受两秒后逐渐加速；失分后新一分应回到发球速度。右侧调节可切经典／渐进／紧张。精准回击只提示，不额外加分。

## v4.7 新功能

- 坦克：打同一掩体三次，检查裂纹、碎裂、缺口通行；贴墙也应能射击。可从右侧设置切换耐久和固定模式。
- 台球：白球落袋后换手，在整桌选点；先试与目标球重叠，再选空位，点自己一端“确认摆球”，随后瞄准击球。
