# 神秘双人小游戏

一台安卓手机，两个人面对面玩。红蓝双方，粗黑描边，暖纸卡，加上一对银灰中分小鸡。

**先看 [开始使用.md](开始使用.md)。当前可安装版本：[v4.7](安装包/当前版本/神秘双人小游戏-v4.7.apk)。**

## 九款游戏都已接入对战

| 游戏 | 操作与获胜 |
| --- | --- |
| 相扑 | 连续点击，把对手推出圈外；保留 v1.8 已打磨的手感 |
| 弹球（原乒乓球） | 左右拖横拍，先得设定分数；按选择保留纯回弹 |
| 冰上桌球 | 拖球槌攻防，先得 5 分 |
| 机关弹珠（原弹球） | 左右独立挡板，宽得分口，三组对称移动机关，回合间随机切换 |
| 赛车 | 一人一个摇杆，依次过检查点，三张赛道 |
| 台球 | 十个目标球＋白球，随机先手，首颗合法进球分色；有限反弹预瞄 |
| 坦克对战 | 一人两个摇杆，履带移动、独立炮塔，三张回合随机地图 |
| 井字棋 | 轮流落子，三子连线；满盘可平局 |
| 五子棋 | 预选后确认落子，五子连线；自由规则，不设禁手 |

每款都有双方准备、开始、结算与再战。进行中可以暂停、重开和返回；声音设置共用并自动保存。大厅底部累计红蓝胜场和平局，可以清零。再战会轮换先手，五子棋始终由先手执黑。

v4.2 将红蓝比分放在左侧纸牌，右侧依次是房屋返回、喇叭音量、滑杆调节、静音图标。上下说明与摇杆朝向双方。每款有相应可调项并单独记忆，保存后重新准备。相扑和井字棋的规则没有重做。详见 [本版记录](docs/v4.4开发记录.md) 与 [新功能选择](docs/新功能候选.md)。

v4.2 修正台球横向压缩，收窄侧栏并改用图标；增加专属音效与赛车引擎、加大赛车摇杆、微缩冰球门、坦克子弹对消和三类移动机关。
